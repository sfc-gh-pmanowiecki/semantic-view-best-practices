# Snowflake Semantic View Best Practices

A comprehensive, self-contained HTML presentation covering best practices for building, optimizing, and debugging Snowflake Semantic Views.

## Overview

This presentation provides practical guidance for working with Snowflake's Semantic Views and Cortex Analyst, including:

- YAML structure and anatomy
- Creation workflows (FastGen and manual)
- Sizing and architecture guidelines
- Optimization strategies for dimensions, metrics, filters, and relationships
- Verified Queries (VQRs) for 40-60% accuracy improvements
- Custom instructions and module instructions
- Audit and quality assurance workflows
- Debug methodologies
- Common pitfalls and anti-patterns

## Usage

Open `semantic_view_best_practices.html` in any modern web browser. The presentation is fully self-contained with no external dependencies.

## Features

- **14 comprehensive sections** covering the full semantic view lifecycle
- **Interactive sidebar navigation** with scroll tracking
- **Syntax-highlighted code examples** for YAML and SQL
- **Visual diagrams and infographics** illustrating key concepts
- **Do/Don't comparison cards** showing best practices vs anti-patterns
- **Snowflake brand styling** consistent with official documentation

## Cortex Code CLI Integration

This presentation is based on the bundled `semantic-view` skill available in Cortex Code CLI. See Section 2 in the presentation for detailed usage instructions and example prompts.
